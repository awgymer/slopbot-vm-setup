## Project overview

A set of configs and scripts to run/install to initialise an Ubuntu 26.04 VM for use running autonomous AI agents i.e. Claude.

## Development guidelines

- Default branch to start from is `main`
- Only one feature/bug should be worked on at a time
- Each feature should get a new branch
- Follow existing code style. Check neighboring files for patterns
- Never co-author commits
- Use "conventional commit" style
- `.devcontainer` stores `vscode` devcontainer setups and is not to be considered part of the codebase
